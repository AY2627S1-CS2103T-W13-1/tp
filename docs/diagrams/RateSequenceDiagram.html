Rating a player

Successful rate 1 8 with an existing first displayed player. Parsing delegates to RateCommandParser; parser internals and object creation are omitted from this overview.

DISPLAYED LIST is getFilteredPersonList(); REPLACE PLAYER is setPerson(player, ratedPlayer). TEAM DATA is getAddressBook(); SAVE TEAM is saveAddressBook(addressBook).

The replacement preserves name, phone, selection status, tags, remark, injury status and jersey number. The current filter stays active; a rating sort may move the player. Invalid indices fail before replacement. Saving happens before the result is returned; a save error leaves the update in memory and reports the failure.
